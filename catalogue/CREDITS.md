# Credits for the sampled instruments Trill offers

Trill ships no recordings. It offers sets of sampled instruments that their makers publish, which a
user fetches from where they are published. These makers ask to be named for theirs; the lines are
theirs to be shown wherever such a set is handed on, and wherever music made with one is released.
The other sets of the catalogue are dedicated to the public domain, and ask for nothing.

This list is written from `catalogue/instruments.toml`; a test holds the two to each other.
